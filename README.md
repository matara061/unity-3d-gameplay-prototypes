# Unity 3D Gameplay Prototypes

A collection of playable 3D gameplay prototypes developed with Unity and C# as part of my game programming portfolio.

## Purpose

This repository documents my exploration of gameplay mechanics, with a focus on character controls, combat systems, AI, and reusable code.

Each prototype will focus on a specific mechanic or system, with a small playable scene to demonstrate its behavior.

## Current Status

Initial project setup. Playable prototypes and documentation will be added as development progresses.

## Technologies

- Unity
- C#

## Prototype Documentation

As prototypes become available, their documentation will include:

- A brief overview of the mechanic.
- Gameplay videos or GIFs.
- Controls and instructions for testing.
- Technical explanations of the implementation.
- Credits for any third-party assets used.
